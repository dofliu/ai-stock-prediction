# AI 股票預測系統 🤖📈

三位 AI 代理人各自開發的股票預測系統，每天推薦 5 檔股票。

## 代理人介紹

| 代理人 | 方法 | 特色 |
|--------|------|------|
| **K** (Claude Code) | 技術指標分析 | RSI、MACD、布林通道、均線多頭排列 |
| **C** (Codex) | ML Ridge Regression | 機器學習橫截面排名 |
| **G** (Gemini) | 基本面 + 動量篩選 | 價值投資結合短期動能 |

## 每日工作流程

```bash
# 1. 執行三位代理人的預測
python run_all_agents.py

# 2. 評估昨日表現（收盤後）
python evaluate_performance.py

# 3. 每週產生長期報告
python weekly_report.py
```

## 輸出範例

```
=======================================================
  K 的每日推薦  [2026-03-11]
=======================================================

#1  2357.TW  華碩
    價格: 531.00  評分: 0.635
    【分析理由】MACD 正值且持續上揚 + RSI 中性偏多 + 量能放大
    【建議理由】短線動能強，適合追漲但需設停損
```

## 共識機制

- 追蹤三位代理人長期表現
- 每週分析共識股票（多位代理人同時推薦）
- 表現不佳的代理人會自動建議調整演算法

## 資料儲存

- `results/predictions_YYYY-MM-DD.json` - 每日預測
- `results/evaluation_YYYY-MM-DD.json` - 每日評估
- `results/weekly_report_YYYY-MM-DD.json` - 每週報告
